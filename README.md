# 🍅 Tomato — Food Delivery Website

Tomato is a full-stack **Food Delivery Web Application** built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.  
It allows users to browse food items, add them to cart, place orders, and manage their accounts seamlessly.

---

## 🚀 Features

### 👤 User Features
- Browse food menu
- Search & filter food items
- Add to cart
- Place orders
- Login / Signup authentication
- Order history tracking

### 🛠️ Admin Features
- Add new food items
- Update or delete items
- Manage orders
- Manage users

---
